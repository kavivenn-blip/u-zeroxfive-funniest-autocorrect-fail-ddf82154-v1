Write one line under 200 characters that reads as a hilarious autocorrect fail. A judge compares entries two at a time and picks the funnier one, weighing the clarity of the slip, the surprise of the wrong word and how well the joke lands on first read.

`main.py` writes a single autocorrect-fail line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`): a text to his wife asking for a new mattress, which autocorrect turned into a mistress — one that sags in the middle and squeaks every time he rolls over at night.

## Run it

```sh
python3 main.py
```
